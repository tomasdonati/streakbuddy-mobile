# Features

This file lists only the main product features and their current scope status.

## Main Features

### Group Challenges
- Status: In MVP (`0.1.0`).
- Fitness challenge is the first and only habit type in MVP.
- Includes group creation, invites, joining, attendance tracking, and leaderboard progress.

### Fitness Planner
- Status: Deferred (placeholder screen only in MVP).
- Full planner functionality (routines and exercises) is planned for a post-MVP release.

### Walkthrough / Education System
- Status: Deferred.
- Reusable onboarding and feature education walkthroughs are planned for a later release.
